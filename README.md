# 🎵 husna's vinyl

A minimalist, interactive personal card designed with a vintage vinyl record player theme.

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](CANLI_SITE_LINKINIZ)

👉 **[Canlı Demo / Live Preview](husna-s-vinyl.netlify.app)**

## ✨ Features

- **Vinyl Record Concept:** A custom digital card experience styled as a spinning vinyl record.
- **Dynamic Tracklist:** Interactive song switching with smooth visual transitions.
- **Aesthetic Typography:** Carefully curated fonts and dark-mode aesthetic styling.
- **Fully Responsive:** Styled to look clean across mobile, tablet, and desktop devices.

## 🛠️ Built With

- **HTML5** & **CSS3**
- **JavaScript**
- **Google Fonts** (*Cinzel Decorative*)
- Hosted on **Netlify** / **GitHub Pages**
